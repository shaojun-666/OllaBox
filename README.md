# OllaBox · 本地模型工作台

> 一个纯本地、零依赖、离线可用的 Ollama 网页客户端。数据不出本机。

当前版本：**v1.2**

OllaBox 是一个单文件网页应用（HTML + CSS + JS 全部内联在 `index.html`），**没有任何外部依赖、不引用任何 CDN、完全离线可用**。它直接调用本机 Ollama 的 HTTP 接口，因此所有的对话、知识库数据都留在你自己的机器上。

---

## 一、前置条件

| 依赖 | 说明 |
| --- | --- |
| **Ollama** | 必须。请先安装并至少 `ollama pull` 一个模型（如 `qwen2.5:7b`）。 |
| **Python 3** | 仅「一键启动」方式需要（用于起一个本地静态服务）。「直开网页」方式不需要。 |
| **Edge / Chrome** | 可选。用于以独立浏览器配置打开，把数据固定在本目录。 |

---

## 二、怎么用

1. 双击 **`启动 OllaBox.bat`**
   - 自动检测并启动 Ollama 服务（如未运行）
   - 启动本地网页服务（默认端口 8788）
   - 用**独立浏览器配置**打开 OllaBox（数据落在本目录的 `browser-profile\`）
2. 在顶栏下拉框选择模型，开始对话。

> 会弹出两个最小化的黑窗口（Ollama 服务、网页服务）。**不要关**，关了服务就停了。  
> 只关网页服务可运行 **`停止 OllaBox.bat`**。

**另一种打开方式**：双击 **`启动 OllaBox (直开网页).bat`** —— 不起网页服务，直接用浏览器打开 `index.html`（`file://` 方式），更轻快、不占端口。

> ⚠️ 建议始终用上面两个启动器打开，而不是直接双击 `index.html`。直接用系统默认浏览器打开时，对话记录和知识库会存到**系统浏览器配置目录**里；用启动器打开则统一存在本目录的 `browser-profile\`，便于备份和清理。

## 三、配置（可选）

如果你的环境比较特殊（Ollama / Python 不在 PATH 里，模型目录在别处），把 `config.example.bat` 复制为 `config.bat`，按需修改：

```bat
@echo off
REM Ollama 可执行文件（不在 PATH 时填完整路径）
REM set "OLLA_CMD=C:\path\to\ollama.exe"
REM Ollama 模型目录
REM set "OLLAMA_MODELS=D:\Ollama\models"
REM Python 解释器
REM set "PY=C:\path\to\python.exe"
REM 网页服务端口
REM set "PORT=8788"
```

启动脚本会优先读取 `config.bat`。该文件已被 `.gitignore` 忽略，不会进入版本库。  
若什么都不配置且命令都在 PATH 中，则开箱即用。

## 四、功能

| 分类 | 能力 |
| --- | --- |
| 对话 | 流式逐字输出、停止生成、重新生成、编辑重发、删除单条、复制 |
| **消息分支** | 同一条提问可保留多个回答版本，用 `‹ 2/3 ›` 来回切换对比；任意消息可「分叉」成一段新对话（原对话不受影响），侧栏用 `⑂` 标记 |
| **RAG 知识库** | 本地文档建库（IndexedDB），提问时自动检索相关段落注入上下文；支持向量语义检索与关键词 BM25 检索自动切换；回答下方可展开查看引用了哪几段资料 |
| **参数预设** | 6 套内置生成参数模式（通用对话/精确事实/代码编程/创意写作/翻译润色/长文总结），含 temperature、top_p、top_k、repeat_penalty、num_ctx、num_predict；可另存为、删除、恢复默认，顶栏一键切换 |
| 多会话 | 无限会话、自动命名、重命名、删除、搜索历史（支持搜正文） |
| 模型 | 下拉切换任意已装模型、显示体积、每个会话独立记忆所选模型 |
| 角色 | 每个对话可设独立系统提示词，内置 6 种角色预设 |
| 渲染 | 自研 Markdown（标题/列表/表格/引用/代码块/链接），代码块一键复制 |
| 统计 | 每条回复显示 tok/s、token 数、耗时 |
| 数据 | 导出单会话为 Markdown（含引用来源、多版本标记）、导出/导入全部会话 JSON（预设一并导出） |
| 外观 | 浅色 / 深色 / 跟随系统，手机窄屏自适应 |
| 运行时 | 查看已加载模型与显存占用、一键卸载释放显存 |
| 快捷键 | `Enter` 发送、`Shift+Enter` 换行、`Ctrl+K` 搜索、`Ctrl+N` 新对话、`Esc` 停止生成 / 关弹窗 |

## 五、三个进阶功能怎么用

### 1. 消息分支（多版本回答 + 分叉）

- **多版本对比**：对任意回答点「重新生成」，旧版本**不会被丢**，而是在同一条消息下新增一版；消息下方出现 `‹ 2/3 ›`，点左右箭头即可来回对比。切换后，后续对话会以你当前选中的那一版作为上文继续。
- **分叉**：点任意消息（自己的或 AI 的）下方的「分叉」，会以「到这条为止」的内容复制出一段**新对话**，标题带 `· 分支`，侧栏有 `⑂` 标记，原对话完全不受影响。适合「同一段前情，往两个方向继续聊」。

### 2. RAG 知识库

顶栏「知识库」按钮 → 新建一个知识库 → 上传文件或粘贴文本。

- **支持格式**：纯文本类 —— `txt / md / csv / tsv / json / log` 以及各类代码（py/js/ts/java/go/sql/yaml…）。自动识别 UTF-8 与 GBK 编码。单文件限 4MB。
- **PDF / Word**：先复制文字，用「粘贴文本」贴进来。
- **启用**：在「本对话启用的知识库」里勾选，按钮会高亮并显示数字角标；只有勾选后提问才会检索。
- **检索方式**（自动选择，界面底部会显示当前是哪一种）：
  - **向量语义检索**：检测到嵌入模型时自动使用（推荐 `nomic-embed-text`）。
  - **关键词 BM25 检索**：没装嵌入模型时的兜底，用中文单字+双字切分 + 英文分词算 BM25 分数，零模型也能用。
- **top-K**：每次检索注入几段资料，默认 4，可调 1–8。
- **引用可见**：回答上方会出现「📚 引用了 N 段知识库资料」，点开可看到具体是哪篇文档的哪一段。
- **升级到语义检索**（可选，约 274MB）：
  ```
  ollama pull nomic-embed-text
  ```
  装完后**新添加**的资料会自动带向量；之前添加的资料仍走关键词检索，想统一可以删掉重新上传。

**资料存哪**：全部在浏览器的 IndexedDB（本机），不上传、不联网。

### 3. 生成参数预设

设置里最上方，或在顶栏第二个下拉框直接切换。

- 内置 6 套，改动下面任意滑块会**自动存进当前预设**（内置的会显示「已修改」）。
- 「另存为」复制成自己的预设；「恢复内置默认」把内置预设还原；「删除预设」移除。
- 每套预设包含：`temperature`、`top_p`、`top_k`、`repeat_penalty`、`num_ctx`、`num_predict`。
- 参数预设是**全局**的（不随对话走），角色/系统提示词是**每个对话各自**的。

## 六、文件说明

```
OllaBox\
  index.html                 ← 整个应用（HTML+CSS+JS 单文件，离线可用）⚠ 主程序本体，勿删勿移
  README.md                  ← 本说明
  启动 OllaBox.bat            ← 一键启动（含 8788 网页服务）
  启动 OllaBox (直开网页).bat  ← 直开 index.html（不起服务）
  停止 OllaBox.bat            ← 停止网页服务
  config.example.bat         ← 本地配置模板（复制为 config.bat 使用）
  browser-profile\           ← 专用浏览器配置（首次启动自动生成，数据都在这）
```

- **对话、设置、预设** → 浏览器 localStorage（键名 `ollabox_v1`）
- **知识库资料与向量** → 浏览器 IndexedDB（库名 `ollabox_kb`）

两者都保存在 `browser-profile\` 里，不占系统盘、不上传。  
迁移用设置里的「导出全部对话 / 导入对话」（知识库不含在导出里，需重新上传）。

## 七、为什么有两个启动器？8788 服务是必须的吗？

不是必须的。实测在 Edge 里，直接用 `file://` 打开 `index.html` 也能正常工作（localStorage、IndexedDB、调用本机 Ollama 都没问题）——`启动 OllaBox (直开网页).bat` 就是这么干的，更轻快、不占端口。

用 8788 静态服务的好处是行为更像「正式网站」，受浏览器针对本地文件的额外限制更少，因此保留为默认方式。两种方式**共用同一个浏览器配置**，数据位置完全一致。

## 九、常见问题

**Q：页面显示「服务未连接」？**  
A：Ollama 没起来。启动 Ollama 服务后，在 OllaBox 设置里点「刷新」。

**Q：回复很慢？**  
A：14B 在 8GB 显存上会部分卸载到内存（约 8–9 tok/s）。日常用 **7B**（约 50 tok/s）。

**Q：聊久了它「忘事」？**  
A：上下文长度由参数预设里的 `num_ctx` 决定，默认 8192。长文档问答可切到「长文总结」预设（32768），但更吃显存。

**Q：知识库搜不准？**  
A：默认是关键词检索。装 `nomic-embed-text` 后新加的资料会走向量语义检索，问法自由也能命中；同时把「检索段落数 top-K」调到 6 试试。

**Q：能上传 PDF 吗？**  
A：暂不支持直接解析，请复制文字后用「粘贴文本」。这是有意的取舍——保持单文件零依赖。

**Q：会联网吗？**  
A：不会。所有请求只发往本机 `127.0.0.1:11434`。

**Q：我的对话记录 / 知识库存在哪？**  
A：存在本目录的 `browser-profile\`（用启动器打开时）。若直接双击 `index.html`，则会落到系统默认浏览器的数据目录。

**Q：想彻底清空 OllaBox 的数据？**  
A：关闭窗口后删掉 `browser-profile\` 目录即可（设置与对话一起清空）；知识库也可以在界面里逐个删库。

**Q：双击启动器后没有打开网页 / 页面打不开？**  
A：启动器会先自检，按提示处理：
1. 若提示「找不到网页主程序 index.html」→ `index.html` 被删掉或挪走了（它是主程序本体），把它放回本目录再运行。
2. 若提示「端口 8788 未就绪」→ 多半是上次的服务还占着端口，先运行 `停止 OllaBox.bat`，再重新启动。
3. 若提示「未找到 Python」→ 安装 Python 并加入 PATH，或在 `config.bat` 里设置 `PY`；急于使用可改用 `启动 OllaBox (直开网页).bat`（不需要网页服务和 Python）。
